## 2. 숫자

### 바꾼 것

- **1일째 신문:** 미리 돌린 마지막 날(0일)의 장 시세와 날씨로 찍는다. 1일째에는 도시에서 먼 마을도 이 신문을 판다. 그래서 사람도 봇도 1일째에 도시 값을 본다(측정에서 보통 사람·장사꾼 봇 모두 1일째에 신문을 샀다: 12명 180자리 중 180).
- **도시 시세 줄:** 도시마다 그날 많이 거래된 물품 4개 → 6개.
- **봇 판단 하나 고침:** 가져갈 마을에 닿았는데 가져온 물건은 없고 다른 짐만 남으면 장사 계획이 지워지지 않아 그 자리에 머물렀다(혼자 돌린 보통 사람 하나가 40일을 머물러 시즌 끝에 손해). 게임 규칙은 그대로다.

## 3. 게임 시작 화면과 부품

### 시작 화면 (견습 전)

- 처음 하는 사람(저장이 없거나 `?new`)은 **상단 이름 → 내 얼굴 → 문장**을 지나 견습으로 간다. 세 단계 모두 추천으로 채워져 "다음 ›"만 세 번 누르면 된다. "추천"은 다시 뽑기, "‹ 이전"으로 돌아간다. 단계마다 노상인 한 줄.
- 상단 이름은 봇 상단 이름 목록에서 추천한다. 로컬은 글자 수(2~12)만 본다. 같은 세계의 봇은 내 이름을 쓰지 않는다.
- 목업이 없어 0.1.6 크림 틀로 그렸다: 위에 1·2·3 단계 표시와 제목, 가운데 고르기, 아래 이전·추천·다음.
- 다음 시즌에는 묻지 않는다(증서와 함께 이어진다).

### 상인 증서

- 가운데에 **얼굴(원형 사진)과 문장**을 나란히, 아래에 **"상인번호 000001"**(목업 꼴). 목업에 사진 자리가 없어 문장 왼쪽에 두었다(질문 135).
- "얼굴 바꾸기 ›", "문장 바꾸기 ›" 페이지에서 언제든 바꾼다(저장을 누르면 바뀐다).
- **상단 이름은 시즌 사이에만:** 시즌 중에는 이름 칸 대신 "상단 이름은 시즌이 끝난 뒤, 다음 시즌을 시작하기 전에 바꿀 수 있어요". 결산 뒤에 칸이 열린다.
- 이미지로 저장에도 얼굴과 문장, 상인 번호를 넣었다(내려받기라 브라우저에서는 아직 보지 않았다. 아래 5장).

### 얼굴과 문장 고르기

- **얼굴:** 피부 3, 머리 3(그림 있는 것 모두, 남녀 구분 없이), 머리색 7, 상의 7, 옷 색 12, 수염(그림이 오면). 추천은 늘 젊은 얼굴(흰머리는 머리색에서 고를 수 있다).
- **문장:** 방패 모양 5, 바탕 색 10, 나눔 무늬 8(없음·세로 반·가로 반·대각 반·띠·십자·갈매기·체크), 무늬 색 10, 상징 10, 상징 색 10. 고르는 줄은 지금 문장에서 그 항목만 바꾼 작은 견본으로 보인다.
- 그림이 오기 전: 방패는 도형, 상징은 짧은 글자(밀·소금·말·열쇠·저울·배·생선·망치·뿔·돈).
- 고르는 동안 위의 미리보기는 붙어 있어 아래 줄을 눌러도 보인다.

### 말

- 마구간에서 꺼내는 말마다 **털색 5**(밤색·갈색·검정·회색·크림)와 **무늬 4**(없음·이마 흰 줄·흰 발목·둘 다)가 세계 시드와 말 번호로 정해진다. 기본 이름은 추천 목록 20개(밤톨, 바람, 구름 …)에서.
- 장부 "인력·말"과 마구간 "내 말"에서 이름 옆 **"이름 짓기"**(1~8글자, 비우면 처음 이름).
- 그림이 오기 전: 점선 빈칸에 털색 점, 이름 아래 "짐말 · 회색 · 이마 흰 줄 · 흰 발목".

### 예전 판

- 0.1.6 저장도 이어진다. 증서의 예전 문장(이름 하나)은 가까운 상징으로(닻 → 돛단배, 모루 → 망치 …), 얼굴은 시드로, 상인 번호는 차례대로 채운다.

## 4. 그림 넣는 법 (문장 부품, 말)

1. `docs/reference/emblem-horse-prompts.md`의 프롬프트로 뽑는다(1254×1254).
2. 원본을 넣는다:
   - 문장: `assets-src/emblem/shield_heater.png` … `shield_oval.png`, `sym_wheat.png` … `sym_purse.png`
   - 말: `assets-src/horse/horse_pony.png`, `horse_draft.png`, `horse_riding.png`, 무늬 `horse_pony_blaze.png`, `horse_pony_socks.png` …(말마다)
3. `npm run parts` → `assets/emblem/`, `assets/horse/`에 512 그림이 생긴다. 커밋하면 다음 빌드부터 화면이 그림을 쓴다(없는 그림은 지금처럼 도형·글자·털색 점).

말 털색은 키트의 색 영역 지도(털 1, 갈기 2)로 바꾸고, 무늬는 무늬 그림에서 원본 몸보다 밝고 흰 곳만 따로 떼어 덮는다. 무늬 그림이 원본과 자리가 조금 어긋나면 무늬도 그만큼 어긋난다. 가짜 그림으로만 시험했다.
