# 0.1.4 작업 목록

기준: `docs/handoff/0.1.4.md`, CHANGELOG 0.1.4, `docs/기획서.md`(0.1.4) "멀티플레이 구조", "NPC 외모".
답을 옮긴 곳: `docs/questions.md` "답이 나온 질문"(104~111, NPC 외모). 이 작업에서 생긴 질문은 112번부터 적는다.

## 순서와 이유

규칙 하나(1)를 바꾸고 숫자를 다시 잰다(2). NPC 외모(3)는 시뮬과 따로라 그다음. 서버 계획(4)은 답과 숫자가 다 나온 뒤에 고친다.

| 순서 | 작업 | 출처 | 기대는 것 | 크기 |
| --- | --- | --- | --- | --- |
| 1 | 인원 → 마을 수: 6~15명 모두 6곳 | 1번(104·105) | 없음 | 작음 |
| 2 | 10·12·15명, 마을 6곳에서 다시 재기 | 1번, 2번(106) | 1 | 작음 |
| 3 | NPC 외모: 파츠 조합 코드와 데이터, 얼굴 자리 | 7번 | 없음 | 중간 |
| 4 | 0.2.0(서버) 작업 목록을 답에 맞춰 고치기 | 3~6번(107~111) | 1, 2 | 중간 |

## 1. 인원 → 마을 수

- `WORLDGEN.townsByPlayers`를 1~5명 4곳, 6~15명 6곳으로. 15명이 넘어도 6곳(서버는 세계를 더 연다).
- 마을 8곳·12곳 맵(`WORLDGEN.sizes[8]`, `[12]`)과 개발용 `&towns=8|12`는 남긴다.

**한 일 (완료):** `townsByPlayers` = `[5, 4], [15, 6]`. 규칙 경계 테스트(1, 5, 6, 10, 11, 12, 15, 16, 20, 50명)와 "10~15명은 모두 6곳" 테스트로 고정했다. 관찰 화면의 봇 여럿 시험 단추(1~20명)는 그대로이고, 10명 넘게 눌러도 마을 6곳으로 열린다.

## 2. 마을 6곳에서 다시 재기

- 10명·12명·15명, 모두 마을 6곳. 시드 5개 × 시작 계절 4개, 125일. 기준은 "12명·마을 6곳".
- 목표: 시즌 평균 15~20, 7일째 12~20, **첫 5일 4~10**(답 106), 10배 번 날 2~3번, 유지비 20~30%, 장사꾼/원정꾼 2~3배, 후반 > 전반.

**한 일 (완료):** 시즌 평균 10명 19.4, 12명 18.4, 15명 15.6으로 모두 목표 안. 0.1.3에서 "규칙 밖 비교"로 잰 값과 똑같다(코드가 같고 마을 수만 규칙에 들어왔다). 첫 5일은 10명 세계만 3.1로 4 아래 → 질문 112. 결과는 `docs/확인목록-0.1.4.md` 2장.

## 3. NPC 외모

- 파츠 목록·팔레트·레이어 순서, 직업별 파츠 범위를 데이터로. 외모 = 시즌 시드 + NPC 번호, 한 세계 안에서 겹치면 다시 뽑기.
- 그림 합성(곱하기)과 그림이 없을 때의 단색 자리표시. 얼굴 자리: 여관 소문꾼, 게시판 일꾼, 노상인, 마을 탭 상인 카드.
- 나중에 플레이어 상인 증서 사진도 같은 구조를 쓸 수 있게.

**한 일 (완료):**
- `src/sim/looks/` (순수 로직, 테스트 12개):
  - `catalog.ts`: 레이어 순서와 곱할 색(뒷머리·눈썹·수염·앞머리 = 머리색, 얼굴·목 = 피부색, 상의 = 옷 색, 모자 = 모자 색, 주근깨·주름 = 그대로), 파츠 목록(뒷머리 4, 얼굴 3, 상의 6, 눈썹 3, 수염 3, 주근깨 1, 주름 1, 앞머리 4, 모자 4), 옷 색 8(천연 염료 5 + 짙은 색 3), 피부 4, 머리 4. 값은 초안.
  - `roles.ts`: 직업 13개의 범위(일꾼 8직업, 여관 주인, 장 상인, 도시 상인, 소문꾼, 노상인). 목록에 같은 것을 여러 번 넣으면 더 자주 나온다.
  - `draw.ts`: 외모 = `mixSeed(시즌 시드, 종류, 번호, 다시 뽑은 횟수)`. 생김새(얼굴, 머리, 피부)와 옷차림(상의, 모자, 옷 색)은 난수를 따로 써서, 일꾼이 일을 바꾸면 옷만 갈아입는다. 겹침은 정해진 차례(노상인 → 여관 주인 → 장 상인 → 소문꾼 → NPC 상단 → 일꾼, 번호순)로 앞사람과 같으면 다시 뽑는다. 앞 차례 얼굴은 뒤에 사람이 늘어도 바뀌지 않는다.
  - `roster.ts`: 세계 명단(`worldNpcs`)과 지금 마을의 얼굴(`townFaces`). 얼굴은 상태에 저장하지 않고 시즌 id와 명단으로 다시 만든다. 봇이 쓰는 `playerView`에는 넣지 않았다(봇 하루가 느려지지 않게).
  - 외모(`Look`)는 누구의 얼굴인지 모르는 데이터라 나중에 상인 증서 사진에 그대로 쓸 수 있다.
- 화면 `src/ui/portrait/`: `portraitHtml(외모, 크기)`가 캔버스 자리를 넣고, 문서에 붙으면 칠한다. 그림은 `assets/portrait/<레이어>/<파츠 id>.png`에 넣으면 그대로 쓰인다(레이어마다 따로, 없는 파츠만 자리표시). 다 그린 초상은 외모·크기마다 하나만 남긴다.
- 얼굴 자리: 여관 소문꾼(이름과 함께), 여관 주인, 게시판 일꾼과 데려온 사람, 견습 카드의 노상인, 마을 탭 시장 카드의 장 상인(작게).
- 관찰 화면(`dev.html`) 아래에 "NPC 얼굴": 직업별로 모아 보기, 시즌을 바꿔 다시 뽑기, 겹치는 얼굴 수.
