# 기획 0.1.4 인수인계

`docs/questions.md` 104~111번의 답이다. 답은 questions.md "답이 나온 질문"으로 옮겨 준다. ★ 질문은 모두 답이 나왔으니 0.2.0(서버) 작업목록에 반영한다.

## 1. ★104·105 세계 크기: 10~15명 모두 마을 6곳

- 마을 수 규칙을 바꾼다: 1~5명 4곳(개발 테스트), **6~15명 6곳**. 8곳·12곳 규칙은 지금 쓰지 않는다(코드는 남김, 나중에 세계를 키울 때).
- 같은 시즌의 세계는 인원과 상관없이 모두 같은 6곳 지도(같은 시드)로 연다. 사람이 모자란 세계도 같은 지도.
- 이유: 12명·6곳 18.4, 15명·6곳 15.6으로 목표(15~20) 안. 마을이 적으면 같은 장에서 자주 만나 경쟁과 소문이 산다.
- 벌이 목표 기준을 "12명·마을 8곳"에서 **"12명·마을 6곳"**으로 바꾼다. 10명·6곳, 15명·6곳도 같이 잰다.

## 2. 106 첫 5일 벌이: 목표 4~10

- 목표를 5~10에서 **4~10**으로. 첫 며칠이 빠듯해야 첫 말·짐꾼의 성장감이 산다.
- 돕는 장치는 넣지 않는다. 6곳으로 재서 보통 사람이 4 아래면 알린다(그때 견습 마을 단골 손님을 2일 늘리는 안을 본다).

## 3. ★107 비공개 테스트 규모

- 기본안 그대로: **세계 2개 × 10~15명, 시즌 1번.** 시즌 전체 랭킹(두 세계 합산)까지 시험한다.

## 4. ★108 봇으로 채우기

- 기본안 그대로: 세계마다 사람이 10명이 안 되면 봇으로 10명까지 채운다. 봇은 지도·신문·내 세계 순위에 보이고, 시즌 전체 순위와 인장·칭호·명예의 전당에서는 뺀다.
- **추가:** 내 세계 순위와 상인 증서 등 봇 상단 이름이 보이는 곳에 작은 "떠돌이" 표시를 붙인다. 사람인 척하지 않는다.

## 5. 109 로그인, 110 알림

- 109: 기본안 그대로. 0.2.0은 구글 계정 + 이메일 링크. 애플 로그인은 앱(Capacitor) 출시 때.
- 110: 기본안 그대로. 0.2.0은 화면 안 알림과 "자리를 비운 사이"만. 웹 푸시는 하지 않고 앱 출시 때.
- 상단 이름 금칙어 걸러 내기는 0.2.0에서 함께(서버가 이름을 받을 때).

## 6. ★111 서버에서 견습

- 기본안 그대로: 견습은 공유 세계 밖의 **혼자 쓰는 작은 세계(견습 마을 하나)**에서 "하루 보내기"로 진행한다. 졸업하면 그날의 공유 세계에 손수레·짐·식량을 들고 들어간다.
- **추가:**
  - 시즌 중간에 온 사람도 견습을 마치면 그날의 공유 세계에 들어간다(들어올 수 있는 마지막 날은 기존 초안 10일째).
  - 견습은 길어도 한두 시간 안에 끝나게 한다. 친구가 "지금 들어와"라고 하면 바로 합류할 수 있게.
  - 견습 세계의 시세·소문은 공유 세계로 가져가지 않는다(가져가는 것은 돈, 짐, 손수레, 식량).

## 7. NPC 외모 생성 (새 기획, 기획서 "NPC 외모")

마을 사람(상인, 여관 주인, 소문꾼, 일꾼)의 얼굴을 파츠 조합으로 시즌마다 뽑는다. 그림은 기획자가 만든다. 이번엔 **조합하는 코드와 데이터 구조**만 만들고, 그림이 없으면 단색 자리표시로 둔다.

- 파츠는 모두 같은 크기(1254×1254) 투명 PNG, 같은 위치 기준.
- 레이어 순서: 뒷머리 → 얼굴·목 → 상의 → 얼굴 파츠(눈썹, 수염, 주근깨, 주름) → 앞머리·옆머리 → 모자·두건. 비어 있는 레이어는 건너뛴다.
- 색은 게임에서 입힌다: 옷과 머리 파츠는 회색조, 팔레트 색을 곱해(multiply) 칠한다. 피부는 얼굴·목 파츠에 피부색을 곱한다. 팔레트:
  - 옷: 쪽빛, 꼭두서니 빨강, 황토, 올리브, 표백 안 한 마 색 (값은 초안, 기획자가 고침)
  - 피부 4가지, 머리 4가지 (초안)
- 직업별 파츠 범위: 직업마다 쓸 수 있는 상의·모자·옷 색 목록을 데이터로 둔다(예: 어부 두건+쪽빛, 광부 가죽 조끼+어두운 색, 여관 주인 앞치마, 도시 상인 진한 색+모자). 그 안에서 뽑는다.
- 시드: NPC 외모 = 시즌 시드 + NPC 번호로 정한다. 같은 시즌의 모든 세계에서 같은 NPC는 같은 얼굴. 한 세계 안에서 같은 조합이 두 번 나오면 다시 뽑는다.
- 얼굴이 나오는 곳: 여관 소문꾼, 게시판 일꾼, 노상인, 마을 탭 상인 카드(자리만 두어도 됨).
- 나중에 같은 시스템을 플레이어 상인 증서 사진에 쓴다. 지금은 데이터 구조만 그걸 막지 않게.
