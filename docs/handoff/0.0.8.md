# 기획 0.0.8 인수인계

0.0.7 확인 목록의 답이다. 답 칸은 확인 문서에 채웠다.

## 고칠 것

1. **겨울 큰 주문 (75-가)**
   - 겨울에 수요 큰 주문 사건(군대 보급, 겨울 축제 등)이 더 잘 뽑히게 한다. 시즌 전체 2~4번은 유지하되 겨울 비중을 높인다.

2. **벌이 목표 (75-다)**
   - "시즌 끝 하루 벌이 50 이상"을 버린다.
   - 새 목표: 보통 봇의 시즌 평균 하루 벌이(숫자는 지금 결과를 보고 정해 알려 주기), 그리고 후반(시즌 뒤쪽 절반) 평균 > 전반 평균. 7일째 20~40은 유지.
   - 테스트·관찰 화면을 여러 시작 계절(봄, 여름, 가을, 겨울)로 돌려 요약한다. 시작 계절은 시즌마다 랜덤이 기획이다.
   - 벌이 재는 법(판 값 − 산 값, 원정 산 값 0)은 그대로.

3. **두 번째 행렬은 큰 주문 도구 (73)**
   - 봇: 징조를 들으면(또는 큰 주문 신문이 나면) 행렬을 그 마을로 보내 모아 둔 물건을 판다. 같은 길을 도는 행렬은 쓰지 않는다.
   - 플레이어 화면: 지시서에 "이 마을로 가서 이것을 판다" 한 번짜리 지시를 쉽게 넣을 수 있게(반복 끄기).
   - 말을 잃으면 어느 마을에서나 손수레로 바꾸는 것은 그대로.

4. **창고 보관료 (74-다)**
   - 창고 하나 단위가 아니라 짐이 차지한 칸 수만큼 하루 보관료. 빈 창고는 싸게(또는 0).
   - 곡물은 그대로(2×2, 한 칸 1개). 곡물은 수레 장사, 시간차 장사의 주인공은 소금.

## 보류

시즌 끝 계절 고정(75-나), 곡물만 높이 쌓기(74-가), 큰 창고(74-나). 곡물이 너무 안 쓰이면 큰 창고를 다시 본다.
