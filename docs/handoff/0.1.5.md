# 기획 0.1.5 인수인계

0.1.4 확인 목록의 답이다(질문 112~114). 답은 `docs/questions.md`에 옮겨 준다. 아이폰에서 볼 것 5가지는 기획자가 해 보고 따로 알려 준다.

## 1. 112 첫 5일 벌이: 봇으로 12명까지 + 마이너스 세계 원인 찾기

- **봇 채우기 기준을 10명에서 12명으로.** 사람이 12명이 안 되는 세계는 봇으로 12명까지 채운다. 벌이 목표의 기준 인원(12명)과 실제로 가장 흔한 세계를 맞추기 위해서다. 0.2.0 작업목록의 봇 채우기 작업도 고친다.
- **첫 5일에 보통 사람이 마이너스인 세계의 원인을 찾는다.** 10명 세계 20개 중 −3.3까지 내려간 세계가 있다. 가장 나쁜 세계 3~5개를 골라 첫 5일에 무슨 일이 있었는지 확인 목록에 적어 준다(예: 시작 마을, 첫 구매, 식량, 첫 장날에 안 팔림, 봇과 같은 길에 몰림). 고치는 것은 원인을 보고 기획에서 정한다.
- 새 기준: 첫 5일 4~10, **보통 사람이 마이너스인 세계가 없을 것.** 12명·6곳에서 다시 재고, 10명·15명도 참고로 함께 잰다.
- 견습 마을 단골 손님 2일 늘리기는 이번에도 하지 않는다(원인을 본 뒤).

## 2. 113 초상 그림 크기

- 그대로: 기획자는 1254×1254로 그리고, 게임에 넣을 때 512로 줄인다. 1254 원본을 둘 자리가 필요하면 `assets-src/portrait/`처럼 게임 빌드에 들어가지 않는 폴더를 정해 준다.

## 3. 114 채운 봇은 시즌 중에 빠지나

- 그대로: 빠지지 않는다. 15명 상한에 봇도 센다.
- **추가:** 새로 들어오는 사람은 사람(봇 빼고)이 가장 적은 세계부터 넣는다. 모든 세계가 15명이면 새 세계를 연다(같은 시즌 시드, 같은 지도). 0.2.0 작업목록에 넣는다.

## 4. NPC 외모

- **상의 4종 추가:** 어부 털실 스웨터, 도시 상인 털깃 겉옷, 농부 튜닉과 멜빵, 대장장이 가죽 앞치마. 목록(`catalog.ts`)과 직업별 범위(`roles.ts`)에 넣는다: 어부 → 스웨터, 도시 상인 → 털깃 겉옷, 농부(곡물 일꾼) → 튜닉과 멜빵, 대장장이 → 가죽 앞치마. 기존 범위에서 빼지는 말고 더한다.
- 짙은 옷 색 셋을 더한 것은 그대로 좋다.
- **프롬프트 ↔ 파츠 id 대응표:** `docs/reference/npc-prompts.md`의 표에서 "파츠 id" 칸을 `catalog.ts`의 id로 채워 준다. 프롬프트에 맞는 파츠가 목록에 없으면(예: 머리 모양) 목록에 새 id로 더하고 표에 적는다. 이 표를 보고 기획자가 그림 파일 이름을 정한다.

## 하지 않는 것

원정(보류), 튜토리얼(기획자가 다시 해 봄), 견습 단골 손님 늘리기(원인을 본 뒤).
