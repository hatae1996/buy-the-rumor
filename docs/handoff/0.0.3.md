# 기획 0.0.3 인수인계

0.0.2의 개발 범위(뼈대, 맵 생성기, 3D 지도, 경제, 화면 뼈대)는 그대로 유효하다. 아래는 그 작업에 반영할 변경이다. 바뀐 기획의 자세한 내용은 `docs/기획서.md`의 해당 섹션을 본다.

## 반영할 것

1. **맵 생성기: 마을 규모 등급** (기획서 "직업" 섹션)
   - 마을에 등급(마을, 소도시, 도시)을 둔다. 테스트 버전은 도시 1 + 생산 마을 3.
   - 도시는 길이 많이 모이는 자리(교통 요지)에 놓고, 자원지가 거의 없다. 자원지 5종은 생산 마을 셋이 나눠 가진다.
   - 생성 규칙 테스트에 위 조건을 추가한다.
   - 지역마다 **특색 태그**(예: 곰이 사는 숲, 늑대가 많은 언덕, 산적이 나오는 길)를 랜덤으로 붙인다. 원정 덱이 이 태그를 읽는다.

2. **경제: 플레이어 피로와 회복** (기획서 "퍼즐 기회와 피로도", "시작 조건")
   - 플레이어에게 피로(0~10)를 둔다. 원정마다 쌓이고, 시간, 음식, 여관으로 회복한다. 음식 소비와 여관비는 경제에 반영한다.
   - 원정 기회: 자원지가 있는 마을에 머무는 동안 게임 속 하루마다 1개, 최대 6개. 이동 중에는 없음.
   - 시작 조건: 모든 플레이어 같은 자금, 등짐 하나. 시작 마을은 고르게 랜덤.

3. **원정 카드** (기획서 "채집: 원정 카드", 프로토타입 `prototypes/expedition.html`)
   - 카드와 덱을 데이터로 정의한다(코드에 박지 않는다). 카드 = 등장 조건 + 선택지 2개 + 각 선택지의 결과 함수.
   - 덱 = 지형 기본 + 지역 특색 태그 + 계절 + 최근 사건 + 내 카드. 연결 카드가 다음 카드를 덱에 넣을 수 있게.
   - 결과는 시드 기반 랜덤으로 계산해 서버 검증이 가능하게.
   - 화면: 카드를 좌우로 넘기거나 선택지를 누른다. 지금은 단순하게, 연출은 나중 버전.

4. **수레 인벤토리** (기획서 "수레 인벤토리", 프로토타입 `prototypes/cart-inventory.html`)
   - 수레 모양 격자(등짐 3×3, 손수레, 짐수레, 마차), 물품별 모양, 끌어다 놓기와 돌리기.
   - **무게 제한**: 물품별 무게, 수레별 최대 무게. 넘으면 출발 불가.
   - **묶음 쌓기**: 같은 물품을 실은 칸 위에 놓으면 합쳐짐. 한 칸 최대 개수는 물품마다 다름(초안: 소금·광석 3, 가죽 4, 목재 2, 생선·고기 2, 곡물·큰 궤짝 1). 무게는 개수만큼.
   - 수레 인벤토리가 플레이어 짐의 실제 저장 구조가 된다(시장 거래와 연결).

## 지우거나 만들지 않을 것

- 채집·사냥 퍼즐. 마을 화면의 "숲으로 나가기(사냥 퍼즐)"는 "원정"으로 바꾼다.
- 수레 옆자리 효과.

## 여전히 이번에 하지 않는 것

멀티플레이와 서버, 시즌 랭킹, 은행, 물품 등급, 신문의 상단 동정, 견습 기간, 푸시 알림
