# 기획 0.1.6 인수인계

0.1.5 확인 목록의 답(질문 115~118)과 기획자가 만든 아바타 키트다. 답은 `docs/questions.md`에 옮겨 준다.

## 1. ★115 봇을 언제 채우나

- 기본안 그대로: 시즌 1일 장날 전까지 온 사람을 먼저 세계에 나눠 넣고(사람이 가장 적은 세계부터), **1일 장날 직전에 사람이 12명이 안 되는 세계만** 봇으로 12명까지 채운다. 기획서 문구도 "12명이 안 되면 12명까지"로 고쳤다.
- 시즌 중간에 모든 세계가 15명(봇 포함)이면, 0.2.0에서는 새 세계를 열지 않고 "다음 시즌을 기다려 주세요"로 둔다. 새 세계를 1일부터 오늘까지 따라잡게 돌리는 것은 나중에.

## 2. 116 첫 5일 마이너스: (가) + (다)

- **(가) 봇도 첫날 신문을 산다.** 신문의 도시 시세를 "아는 시세"로 기억해, 집 앞에서 싼 것을 실어 도시로 갈 수 있게 한다. 봇을 사람에 가깝게 하는 것이고 게임 규칙은 그대로다.
- **(다) 견습 졸업 때 그날 공유 세계의 신문 한 부를 준다.** 견습 7장면 "손수레를 선물로 받고"에 신문을 더한다. 노상인 한 줄 예: "가는 길에 읽어 보게. 도시 값이 실려 있지."
- 다시 잰다(12명 기준, 10·15명 참고): 첫 5일, 마이너스 세계 수, **첫 5일 판 이익(참고 숫자로 새로)**, 시작 마을 묶음별(도시 시작 / 도시까지 1·2·3·4일+) 첫 5일.
- (나) 시작 마을 규칙과 (라) 지표는 그대로. 다시 잰 뒤에도 도시에서 시작한 사람이 다른 묶음의 2배를 넘으면 알린다(그때 시작 마을 규칙을 본다).

## 3. 117 로컬 봇

- 로컬은 나 + 봇 **11명**(모두 12명, 서버 기준과 같게). 개발용 설정(0~20)은 그대로.

## 4. 118 NPC 외모: 아바타 키트 방식으로 바꾼다

기획자가 `assets-src/portrait/avatar-kit/`에 키트를 만들었다. 먼저 키트의 `README.md`를 읽는다. 0.1.4~0.1.5의 파츠 구조(앞뒤 머리, 얼굴·목 3, 눈썹·주근깨, 모자, 회색조 곱하기)를 이 방식으로 바꾼다.

**키트의 방식**
- 베이스 캐릭터 한 명(`base.png`, 얼굴·목 포함, 민머리) 위에 상의·머리·나이를 겹친다. 모든 그림 1254×1254, 같은 위치.
- 파츠마다 세 장: `이름.png`(본체, 투명), `이름_mul.png`(피부에 드리우는 그림자, 곱하기, 흰색 = 변화 없음), `이름_reg.png`(색 영역 지도: 1 주 색, 2 보조, 3 보조2, 255 고정 장식, 0 투명).
- 겹치는 순서: 베이스(피부색 곱하기) → 노인이면 눈썹 회색 + `age_01_mul` 곱하기 → `top_mul` 곱하기 → `top` → (수염: `beard_mul` → `beard`) → `hair_mul` 곱하기 → `hair`.
- 색 바꾸기는 `regions.py`의 `recolor`: 영역마다 Lab 밝기를 목표 색으로 옮기고 원래 명암 차이는 유지. 피부 3가지, 머리색, 옷 색 값은 `render.py`의 `SKIN`, `HAIR_COLORS`, `CLOTH`, 노인 머리 `GRAY_HAIR`.
- 키트의 `previews/random_sheet.png`가 목표 모습이다.

**게임에 넣는 법 (제안, 더 나은 방법이 있으면 그쪽으로)**
- 빌드 전 스크립트(파이썬, 키트 코드 재사용)로 `assets-src`에서 `assets/portrait/`로 512 크기를 만든다.
  - 베이스는 배경을 투명하게 하고, 피부 3 × (젊음 / 노인: 회색 눈썹 + 주름) = 6장을 미리 만든다(눈썹 바꾸기는 거리 변환이라 미리 하는 게 낫다).
  - 파츠 본체와 `_mul`은 보통 줄이기, **`_reg`는 nearest로 줄인다**(영역 번호가 섞이면 안 된다).
- 게임은 베이스 한 장 + 파츠마다 `recolor`(TS로 옮김) → 곱하기 → 덮기만 한다. NPC마다 한 번 그려 캐시.
- 그림이 없는 파츠(새로 뽑을 파츠)는 목록에만 두고 뽑지 않는다. 자리표시 그림은 이제 쓰지 않는다.

**바뀌는 것**
- 얼굴이 하나다. 사람마다 다른 것은 피부색, 머리 모양·색, 노인 여부, 상의·옷 색, 수염. 그래서 **직업은 상의와 옷 색으로 알려 준다.**
- 쓰지 않는 것: 앞뒤 머리 나누기, 모자·두건, 얼굴·목 파츠 3, 눈썹·주근깨 파츠. 0.1.5의 "머리 모양 한 벌"은 한 장짜리 머리라 자연히 해결된다.
- 수염 레이어(`beard`)를 새로 둔다. 남자 얼굴에만, 직업마다 확률(초안: 어부·대장장이·광부 50%, 도시 상인 30%, 나머지 15%). 수염 색 = 머리색.
- 노인: 노상인은 항상 노인(`hair_03` 자주, `top_06` 또는 `top_08`). 그 밖은 25%(초안).

**직업별 범위 (초안, `docs/reference/npc-prompts.md`의 표)**

| 직업 | 상의 | 옷 색 |
| --- | --- | --- |
| 어부 | top_13(없으면 top_05), top_03 | 쪽빛, 짙은 쪽빛 |
| 광부 | top_09, top_07 | 짙은 색 |
| 사냥꾼 | top_09 | 올리브, 갈색 |
| 농부·나무꾼·염장꾼 | top_07, top_03 | 표백 안 한 마, 황토 |
| 여관 주인 | top_10(없으면 top_04) | 크림, 황토 |
| 대장장이 | top_11(없으면 top_09) | 짙은 갈색 |
| 도시 상인 | top_08, top_06 | 꼭두서니, 짙은 색 |
| 소문꾼·마을 사람 | top_03, top_04, top_07, top_12 | 아무 색 |

- 상의 id는 키트 파일 이름(`top_03` 등)을 그대로 쓴다. 0.1.5의 이름(`sweater`, `furCoat`, `braces`, `leatherApron` 등)과 대응표는 키트 이름으로 바꾼다.
- `docs/reference/npc-prompts.md`를 새로 썼다(키트 방식 프롬프트 10개: 상의 4, 머리 4, 수염 2). 기획자가 뽑아 키트에 넣으면, 다음 빌드에 자동으로 들어가게 해 준다(목록에 있고 그림이 있으면 쓴다).

## 아이폰에서 볼 것 (다음 확인 목록에)
