# 기획 0.0.5 인수인계

0.0.4까지의 범위는 그대로 유효하다. 아래는 그 위에 반영할 변경이다. 자세한 내용은 `docs/기획서.md`의 해당 섹션을 본다.

## 반영할 것

1. **성장: 단계 없음** (기획서 "성장")
   - 단계·등급·해금 조건을 만들지 않는다. 0.0.4까지 문서에 "상단 단계부터" 같은 조건이 있었다면 지운다(정보원, 지도 기본 화면).
   - 살 수 있는 것을 데이터로 정의한다: 종류, 오르는 능력, 파는 곳(건물), 값, 유지비. 숫자는 플레이어 봇으로 맞춘다.
   - 목표: 평범한 봇이 시즌 3일쯤 첫 말이나 짐꾼, 7일쯤 첫 채집꾼이나 창고. 두 번째 행렬은 잘하는 봇만.
   - 일꾼은 그 마을 NPC 일꾼 중에서 고용한다(마을 생산이 줄어든다). 일당은 그 마을 일손 사정에 따라. 일당을 못 주면 떠난다(빚이 되지 않음).
   - 채집꾼: 카드 선택 없이 평균 결과로 매일 원정, 결과는 그 마을 창고로. 짐꾼: 내 행렬에 손수레 하나 추가.
   - 창고: 마을마다 빌리는 칸 판. 음식은 창고에서도 상한다. 창고 짐으로 그 마을 장날에 팔기 가능(내가 없어도).
   - 두 번째 행렬: 마부 + 말 + 수레. 지시서(마을 순서, 마을마다 사기/팔기와 가격 한도, 반복 여부)대로 장날에 신청한다. 마부는 소문을 보고 지시를 바꾸지 않는다. 짐은 알아서 싣기(칸 80%).
   - 말 2필 제한은 유지. 마차(2필)를 쓰면 두 번째 행렬을 못 만든다.
   - 작업장(염장소, 대장간)과 대출은 구조만 두고 나중에.

2. **화면 흐름** (기획서 "화면 구성", 시안 `prototypes/screens-0.0.5.html`)
   - 탭은 4개 그대로. 새 기능은 아래 자리에 넣는다.
   - 마을 탭: 그 마을에 있는 건물만 카드로. 시장·여관·잡화점·창고는 모든 마을, 바깥(원정)은 자원지 마을, 마구간은 목장 마을, 수레방은 목재 마을과 도시, 작업장·은행·길드 회관은 도시. 할 일이 있으면 카드에 도장(!).
   - 여관: 소문꾼(2~3명), 술 한 잔, 묵기, 고용 게시판(짐꾼, 채집꾼, 마부, 정보원).
   - 장부 탭: 짐(행렬별 수레 판, 창고), 신청, 사람과 말(하루 유지비 합계), 시세, 돈.
   - 소식 탭: 신문, 소문 수첩, 보고(장날 결과, 일꾼·마부·정보원), 길드(의뢰, 랭킹).
   - 지도 탭: 마을 정보 카드, 행렬 카드, 지시서 편집.
   - 위쪽 줄: 날짜·계절, 장날까지 남은 시간, 소지금, 피로, 내 문장(누르면 상인 증서).
   - "자리를 비운 사이" 요약은 최대 5장(장날 결과 → 급한 일 → 신문 → 보고 → 소문).

3. **은행은 도시에만** (기획서 "은행"). 계좌는 하나, 어느 도시에서나 같다(초안).

4. **알림** (기획서 "시간과 접속 리듬")
   - 이번엔 알림 종류와 설정 데이터 구조, 그리고 "알림을 보낼 사건" 목록만. 실제 푸시는 서버 버전에서.

5. **멀티플레이를 위한 준비** (기획서 "멀티플레이 구조")
   - 지금은 서버를 만들지 않는다. 대신 시뮬 코드가 서버에서도 그대로 돌 수 있게 지킨다(화면·시간 API 없음, 모든 행동은 명령, 시드 랜덤).
   - 플레이어에게 보내는 정보(알고 있는 시세, 들은 소문, 가 본 마을)와 진짜 상태를 계속 분리한다. 나중에 서버가 이 경계로 데이터를 보낸다.
   - 수레 싣기는 "최종 배치"를 명령으로 보내고 시뮬이 모양·무게를 다시 검사한다.
   - 플레이어끼리 직접 주고받는 기능은 만들지 않는다.

## 하지 않는 것

서버와 계정, 실제 푸시, 랭킹 화면과 시즌 결산, 시즌 테마와 길드 의뢰(보류), 작업장과 대출의 실제 동작, 채팅, 수익화 기능
