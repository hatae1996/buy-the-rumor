# 0.0.1 내용 (그대로 유효)

첫 인수인계다. 기획의 큰 구조는 정해졌고, 이번 개발 목표는 **혼자서 돌아가는 세계 하나를 아이폰에서 띄우는 것**이다. 멀티플레이와 서버는 아직 하지 않는다.

## 이번에 만들 것 (순서대로)

1. **프로젝트 뼈대**
   - Vite + TypeScript + Three.js + Vitest 설정, `CLAUDE.md`의 폴더 구조
   - 아이폰 사파리에서 열리는 빈 화면과 홈 화면 추가용 매니페스트
   - 미리보기 배포 방법 정리 (README에 적기)

2. **맵 생성기 (`src/sim/worldgen`)**
   - `prototypes/hexmap-2d.html`의 생성기를 옮긴다: 반지름 7칸 육각 맵, 노이즈 높이와 습도로 지형 6종, 자원지 5종, 마을 4개, 길, 이동 일수
   - 생성 규칙을 테스트로 고정한다: 자원지 5종이 모두 어느 마을 근처에 있음, 마을 특색은 최대 2개, 모든 마을 연결, 가장 가까운 마을 1~4일
   - 같은 시드면 같은 맵

3. **3D 지도 (`src/view3d`)**
   - `prototypes/hexmap-3d.html`을 바탕으로 육각 기둥, 소품, 마을, 길, 보드게임 말
   - 마을을 누르면 말이 길을 따라 이동, 계절 4개 표현(겨울 눈)
   - 그림체를 UI에 맞추는 실험: 기둥 윗면에 땅 그림 질감, 툰 셰이딩과 외곽선

4. **경제 시뮬레이션 (`src/sim/economy`)**
   - `prototypes/economy-sim.html`의 로직을 기획서 기준으로 다시 만든다
   - 마을 4개, 물품 9개, 직업 8개, 계절, 음식 부패, 일꾼의 식사·도구·세금·전직·이주
   - **장날 정산(동시호가)**: 하루 동안 모인 신청을 하루 끝에 한 가격으로 정산
   - 개발용 관찰 화면(`src/dev`)에서 300일 이상 돌려 붕괴나 폭주가 없는지 확인

5. **플레이어 화면 뼈대 (`src/ui`)**
   - 자리를 비운 사이 요약, 마을(기본 화면), 판매 신청, 장부, 신문
   - 아래 탭 4개: 마을, 지도, 장부, 소식
   - `assets/ui`의 그림 사용. 참고 시안: claude.ai의 "상인의 장부 화면 시안" (E. AI 에셋 적용)

## 이번에 하지 않는 것

멀티플레이와 서버, 시즌 랭킹, 은행, 채집 퍼즐, 물품 등급, 신문의 상단 동정, 견습 기간, 푸시 알림

## 프로토타입 메모

- `prototypes/economy-sim.html`: 첫 경제 시뮬레이터. 마을 3개, 물품 7개 기준이라 기획서와 다르다. 균형을 잡으며 겪은 문제(모두 사냥꾼이 됨, 창고 넘침, 인플레이션)와 해결책(예상 수입 기반 전직, 직업별 인원 상한, 창고 한도, 세금과 상납)이 코드에 남아 있다.
- `prototypes/hexmap-2d.html`: 맵 생성기 원본. 400개 시드에서 실패 0, 평균 1.2번 만에 규칙 통과.
- `prototypes/hexmap-3d.html`: 3D 디오라마. Three.js r128을 CDN에서 불러온다.
- `prototypes/hexmap-tiles/`: AI 그림 타일을 깐 2D 버전. 3D로 가기로 정해서 참고용이다.
