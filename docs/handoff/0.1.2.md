# 기획 0.1.2 인수인계

기획자가 0.1.0을 아이폰에서 직접 해 보고 나온 피드백이다. 숫자보다 손에 닿는 화면과 흐름 이야기다. 0.1.1(마을 수와 NPC 경제)과 함께 하되, 0.1.1의 맵·경제 작업을 먼저 하고 이것을 이어서 해도 된다. 자세한 내용은 기획서 "화면 구성 - 직접 해 본 뒤 고친 것 (0.1.2)"과 "수레 인벤토리 - 짐칸 화면".

## 고칠 것

1. **하단 탭 5개:** 마을 · 지도 · 짐칸 · 장부 · 소식. 견습에서 탭이 열리는 순서도 맞춘다(짐칸은 첫 짐 싣기 때).

2. **짐칸 화면** (참고 목업 `docs/reference/cart-inventory-mockup.png`, 게임 DREDGE의 배 짐칸)
   - 수레 그림 위에 수레 모양 칸. 물품은 그림이 자기 칸을 채우고 묶음 수 구석 표시. 그림 에셋이 없으면 지금은 아이콘·이름으로 대신하고 에셋은 기획자가 만든다.
   - 위쪽 무게 막대, 누르면 아래 정보판(이름, 칸·무게, 산 값, 남은 신선도, 내가 아는 이 마을 시세).
   - 장비(활, 그물, 덫, 횃불)는 짐칸 자리를 차지한다. 실은 장비만 쓴다.
   - 칸 손상: 길 위 사건(산적, 낙석, 험한 길)이 칸을 망가뜨릴 수 있다. 망가진 칸은 X, 실을 수 없고 그 칸의 짐은 잃는다. 수레방에서 칸마다 돈을 내고 고친다. 확률·값은 초안으로 두고 알려 주기.
   - 창고·장날 결과 받기는 두 판을 위아래로 놓고 끌어 옮긴다.
   - "빈칸 정리": 짐을 한쪽으로 모아 붙이는 단순 정리. 최적 배치는 아니다.

3. **장부:** 작은 탭 4개(신청: 장날·예약 / 가계부: 돈 내역과 손익 / 시세 / 사람과 말).

4. **이동 중 마을 탭:** "리버포드 ~~~→ 솔트미어 이동 중, 도착까지 3시간 20분(실제 시간)". 길 그림 위 내 말, 남은 식량, "도착하면 팔기".

5. **신문**
   - 신문은 마을에 있을 때 신문팔이(마을 탭 카드)에게서 그날 것을 산다. 길 위에서는 못 산다. 값 2냥 그대로.
   - 발행 날짜를 붙인다. 도시 신문사에서 먼 마을(도시에서 하루 넘는 거리)은 하루 늦은 신문이 온다(초안, 해 보고 어색하면 빼도 됨).
   - 소식 탭에 산 신문 목록(날짜순, 안 읽음 표시). 누르면 그 신문 한 부 전체.
   - "자리를 비운 사이"는 산 신문의 머리기사만.

6. **소문 수첩**
   - 소문은 여관 소문꾼 "듣기"로만 들린다. 밤마다 저절로 수첩에 적히지 않는다(0.0.6의 60번 답을 바꿈).
   - 들은 뒤 "수첩에 적기 / 흘려듣기". 적은 것만 수첩, 도장도 적은 것에만. 흘려들은 것은 며칠 "최근 들은 이야기"에 있다가 사라진다.
   - 수첩은 확인 기다림 / 맞음 / 틀림, 물품별 찾기.
   - 자리를 비운 사이엔 "여관에 새 소문" 표시만.
   - 봇은 지금처럼 들은 것을 바로 쓴다(봇은 적기 단계 없이).

7. **식량**
   - 이동하는 날마다 사람 1명당 식량 1(짐꾼·마부 포함). 수레의 음식 물품(염장 식품, 곡물, 고기, 생선) 중 먼저 상할 것부터 먹는다. 잡화점 "여행 식량" 꾸러미(한 칸, 값은 곡물·염장 시세 연동).
   - 떨어지면 하루마다 피로 크게 오르고 이동이 느려진다. 죽거나 짐을 잃지는 않는다.
   - 이동 계획에 "필요한 식량 n"을 보여 준다.
   - 봇도 식량을 산다. 벌이 목표가 크게 흔들리면 알려 주기.

8. **지도의 내 위치:** 내 말을 크게, 나만 쓰는 색, 발밑 빛나는 고리, "내 위치로" 버튼.

## 하지 않는 것

- **원정:** 보류. 지금 그대로 두고 카드 추가나 숫자 맞추기를 하지 않는다.
- **튜토리얼:** 기획자가 다시 해 보고 정한다. 이번엔 새 탭·신문 사기·소문 적기에 맞춰 견습 장면만 맞춘다.
