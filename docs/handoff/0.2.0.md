# 기획 0.2.0 인수인계 (서버와 비공개 테스트)

개발 쪽 계획 `docs/작업목록-0.2.0.md`를 기획이 받았다. **구조와 순서(1~13번)는 그대로 간다.** 이 문서는 그 계획에 기획이 정한 것을 더한다. 기획서 "멀티플레이 구조"에 "비공개 테스트 운영"을 새로 넣었다. 0.1.7 결과 전달의 답(131~135)도 끝에 있다. 답은 `docs/questions.md`에 옮기고, 작업목록-0.2.0을 이 문서에 맞춰 고친 뒤 시작한다.

## 1. 들어오는 법: 초대 코드 (4번, 8번)

- 계정을 만들 때 초대 코드를 넣어야 한다. 코드는 운영자가 만든다(여러 번 쓰는 코드 하나든, 사람마다 코드든 개발에서 편한 쪽으로).
- 운영자가 시즌을 열 때 세계 둘을 미리 연다(작업목록 8번의 말대로).
- 코드 없는 사람은 로그인 뒤 "초대 코드를 넣어 주세요" 화면에서 멈춘다.

## 2. 예행연습 (13번)

- 봇으로 서버 시즌을 한 번 끝까지 돌린 다음, **지인 2~3명과 3~4일** 먼저 해 본다. 시험 모드로 날을 빠르게 하지 않고 실제 시간으로.
- 볼 것: 로그인과 초대 코드, 시작 화면, 견습 → 졸업 → 공유 세계 들어가기, 장날이 빠지지 않는지, "자리를 비운 사이", 아이폰 사파리에서 끊겼다 다시 이어지기.
- 예행연습에서 나온 문제를 고친 뒤 비공개 테스트(세계 2개 × 10~15명, 시즌 1번)를 연다. 예행연습 세계는 비공개 테스트 전에 지운다(증서·인장도 남기지 않는다).

## 3. 시즌 중 업데이트 규칙 (3번, 운영)

- **시즌 중에는 시뮬 규칙과 숫자를 바꾸지 않는다.** 같은 시즌의 세계는 같은 규칙이어야 랭킹을 합칠 수 있다. 숫자를 바꾸는 것은 다음 시즌부터.
- 시즌 중에 고쳐도 되는 것: 화면, 글, 그림, 서버 쪽 버그(장날이 안 돌았다 등), 상태를 바꾸지 않는 시뮬 버그.
- 게임을 망가뜨리는 시뮬 버그(돈이 복사된다, 짐이 사라진다 등)가 나오면: 그 시즌을 **"시험 시즌"**으로 표시하고(랭킹·인장 없음), 고친 뒤 새 시즌을 연다. 장날 결과를 하나씩 되돌리지는 않는다. `commands` 기록은 원인을 찾는 데 쓴다.
- 배포할 때 세계 상태(`EconomyState`)와 맞지 않는 시뮬 코드가 올라가지 않게, 상태에 시뮬 버전을 적고 다르면 장날을 멈추고 알린다(개발에서 편한 방식으로).

## 4. 기록할 숫자 (13번에 더한다)

작업목록 13번의 "첫 5일 기록"에 더해, 사람마다:
- **처음 흐름:** 시작 화면에 걸린 시간, 견습 시작부터 졸업까지 걸린 시간(실제 시간), 졸업부터 첫 거래 체결까지 걸린 시간.
- **접속:** 날마다 들어온 횟수와 머문 시간(대략, 화면을 연 동안), 마지막으로 들어온 날.
- **시스템을 쓰는지:** 신문을 산 날 수, 소문 "적기 / 흘려듣기" 수, 예약 주문 수, 두 번째 행렬을 꾸렸는지, 말을 샀는지, 짐꾼·일꾼을 고용했는지.
- **독점(답 92):** 사람 기준으로도 센다(0.1.7 질문 133).
- 시즌 끝에 개발용 관찰 화면이나 파일로 한 표로 볼 수 있게. 개인을 알아볼 수 있는 것(이메일)은 표에 넣지 않고 상인 번호로.

## 5. 의견 받기 (11번)

- 게임 안 **"의견 보내기"** 버튼: 상인 증서 페이지(또는 설정)에 하나. 글을 쓰면 상인 번호, 그날 날짜(게임 날과 실제 시각), 지금 화면 이름과 함께 표(`feedback`)에 저장. 사진 첨부는 하지 않는다.
- 시즌 결산 화면에 **설문 링크** 한 줄("이번 시즌 어땠나요?"). 링크 주소는 기획자가 준다(없으면 자리만).

## 6. 테스트 뒤 데이터

- 비공개 테스트의 인장·칭호·명예의 전당은 **정식 출시 때 초기화**한다.
- 남는 것: **상인 번호**, 상단 이름·얼굴·문장, 그리고 테스터 전용 인장 **"개척 상인"**(비공개 테스트 시즌을 결산까지 마친 사람, 하루라도 들어온 사람이면 충분). 인장 그림은 기획자가 준다(없으면 등급 색 메달).
- `certificates`에 "테스트 시즌" 표시를 두어, 초기화할 때 무엇을 지울지 가를 수 있게.

## 7. 금칙어와 이름 (4번)

- 금칙어는 공개된 한국어 욕설 목록(라이선스 확인) + 운영자가 직접 더하는 목록. 띄어쓰기·기호 섞기 잡기는 작업목록대로.
- 같은 상단 이름은 **시즌 전체(모든 세계)**에서 한 사람만. 봇 이름은 사람 이름과 겹치지 않게(0.1.7 로컬과 같게).

## 8. 시간

- 모두 **한국 시간(Asia/Seoul)**. 시즌은 격주 월요일 아침 9시에 연다. 장날 시각도 한국 시간 기준.
- 조용한 시간(밤 11시~아침 8시)의 화면 안 알림은 아침에 모아 보여 준다(푸시가 없으니 다음에 열 때 정리해서).

## 9. 개인정보

- 저장하는 것: 이메일(로그인), 플레이 기록, 의견. 로그인 화면에 한 줄: "테스트용 게임이며 이메일과 플레이 기록만 저장합니다."
- 계정 지우기를 부탁받으면 운영자가 지운다(화면 기능은 만들지 않는다).

## 10. 홈 화면에 추가 안내

- 견습 졸업 때 한 번만 쪽지로: "홈 화면에 추가하면 주소창 없이 꽉 찬 화면으로 열려요." 사파리 공유 단추 그림 한 줄. 다시 보지 않기.
- 홈 화면에서 열었을 때 노치·홈 바가 가리지 않는지 아이폰 확인 목록에 넣는다.

## 11. 0.1.7 결과 전달의 답 (131~135)

- **131 "시즌 전날 신문":** 그대로.
- **132 봇의 상인 번호:** (가) 로컬은 그대로(2~12번), 서버 봇은 번호 없이 "떠돌이".
- **133 12명 독점 1 → 6/20:** (나)를 가볍게. 늘어난 세계 다섯의 마을·물품·사람(보통 사람 / 장사꾼 봇 / 원정꾼)을 확인 목록에 적기만 한다. 고치지 않는다. 비공개 테스트에서 사람 기준으로 다시 본다.
- **134 문장 색·무늬:** 그대로. 단, **작은 자리(36px 이하: 위 줄, 랭킹)에서는 상징 글자를 빼고 방패와 색만** 그린다. 그림이 오면 다시 본다.
- **135 증서 얼굴 자리:** (가) 목업이 올 때까지 지금처럼(문장 왼쪽).
- **바깥·원정:** 보류 그대로.
- **곡물(답 127 측정):** 손수레 세로형으로 곡물 사서 옮기기가 45% 줄었다. 다음 측정 때 **봄 구휼 큰 주문이 채워지는지**(낸 사람, 팔린 양) 함께 적는다. 안 채워지면 곡물 모양을 기획에서 다시 본다.

## 하지 않는 것

원정 다시 보기, 튜토리얼, 은행·소량 즉시 거래·길드 의뢰, 채팅, 웹 푸시·애플 로그인·앱 출시, 시작 마을 규칙(비공개 테스트 숫자를 본 뒤), 새 세계 따라잡기(시즌 중간에 모두 차면 다음 시즌 대기).
