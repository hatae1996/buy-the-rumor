# 기획 0.0.7 인수인계

0.0.6 확인 목록의 답이다. 답 칸은 확인 문서에 채웠다.

## 방향

물량을 늘려 크는 길(같은 길로 더 많이 나르기)은 장이 넘쳐 금방 막히고, 멀티에서는 여러 사람이 나눠 써서 더 빨리 막힌다. 그래서 하루 벌이가 매일 꾸준히 오르는 것을 목표로 하지 않는다. 평소 벌이는 작고, **사건을 미리 읽은 사람이 크게 버는 날**이 있게 한다. 게임 제목 그대로다.

## 고칠 것

1. **큰 주문 사건 (다)**
   - 수요 사건(조선소 대형 상선, 영주의 성 보수, 군대 보급, 축제)에 "큰 주문"을 붙인다: 정해진 마을에서, 정해진 기간 동안, 한 물품을 많이(예: 목재 300개) 높은 값(예: 기준가 1.5배)에 산다. 주문량이 다 차면 끝.
   - 대상단 도착도 같은 방식으로 "사 가는 쪽"을 더 크게.
   - 징조 소문 → 신문 → 주문 기간 순서. 징조 때 사서 쌓아 둔 사람이 이득이고, 신문 보고 움직인 사람은 늦어서 덜 번다.
   - 주문은 장날 정산에 함께 들어가는 큰 사자 신청으로 처리해도 되고, 시장 옆 따로 받는 창구로 해도 된다(구현이 단순한 쪽).
   - 시즌에 2~4번. Buy the Rumor 부문 기록이 여기서 주로 나오게.

2. **시간차 장사 (마, 새로 추가)**
   - 계절 값 차이(가을 곡물 쌈 → 겨울 비쌈, 여름 생선·소금 쌈 등)가 창고 보관료와 상하는 것을 넘을 만큼 있는지 확인하고, 모자라면 계절 생산·수요 배율을 키운다.
   - 봇(특히 장사꾼)이 창고에 쌓았다가 계절이 바뀌면 파는 장사를 하게 한다.

3. **말 (나)**
   - 시즌 말 수 = 플레이어 수에 비례(혼자일 때도 구할 길이 있게. 초안: 혼자면 시즌 8~10마리).
   - 마구간 마을(목장 특색)은 맵마다 꼭 2곳.

4. **목표 (라)**
   - 보통 봇 하루 벌이: 첫날 5~10 → 7일째(약 67일) 20~40 → 시즌 끝 50 이상
   - 유지비는 벌이의 20~30% 안(그대로)
   - **새 목표:** 보통 봇이 시즌에 "그날 벌이가 평소 하루 벌이의 10배 이상인 날"이 2~3번. 관찰 화면 요약에 이 횟수를 보여 준다.
   - 장사꾼 순자산이 원정꾼의 2~3배(0.0.6에서 달성, 유지)

## 하지 않는 것

- (가) 도시를 둘로 늘리거나 도시 수요를 더 키우기
