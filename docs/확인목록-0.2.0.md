# 0.2.0 확인 목록

기획 0.2.0(서버와 비공개 테스트)을 만든 결과다. 작업마다 한 일은 `docs/작업목록-0.2.0.md`, 열린 질문은 `docs/questions.md` 136~139, 운영자가 할 일과 명령은 `supabase/README.md`.

**아직 실제 Supabase에 올리지 않았다.** 계정과 키는 운영자가 만들어야 해서, 서버 코드는 모두 로컬에서 시험했다: 표와 함수 몸통은 PGlite(WASM Postgres), Edge Function 껍데기는 Deno로 띄워 postgres.js로 PGlite 소켓에 붙이고 로그인 토큰을 시험 안에서 서명했다. pg_cron이 실제로 부르는지, 구글·이메일 로그인, 메일 발송은 프로젝트를 만든 뒤에 본다.

## 2. 운영자가 할 일 (순서대로)

자세한 명령은 `supabase/README.md`.

1. Supabase 프로젝트(서울), `npx supabase login`, `init`, `link`, `db push`.
2. 비밀 값 둘: `TICK_SECRET`(함수 환경 + Vault `tick_secret`, `project_url`), `ADMIN_SECRET`.
3. `npm run build:server` 뒤 함수 다섯: `health`, `tick`·`admin`(`--no-verify-jwt`), `account`, `game`.
4. `health`를 불러 로컬 해시와 같은지.
5. 로그인 설정: 주소(Site URL, Redirect URLs), 이메일 링크, 구글 OAuth 클라이언트. 테스터가 많아지기 전에 SMTP.
6. 게임 빌드에 `.env.production.local`(서버 주소, 공개 키). GitHub Pages로 올리려면 배포 워크플로가 이 값을 넘기게 고친다(저장소에 원격이 아직 없다).
7. 예행연습: `admin`으로 `rehearsal` 시즌(세계 하나 또는 둘), `make_invite_codes`로 코드, 지인 2~3명과 3~4일. 끝나면 `deleteSeason`.
8. 비공개 테스트: 월요일 시즌을 `closed_test`로, 세계 둘. 시즌 중에는 시뮬 규칙·숫자를 바꾸지 않는다.

- tick 시간은 PGlite 안에서 상태 읽기·쓰기를 포함한 것. Edge Function 요청당 CPU 한도(약 2초) 안이다.

### 측정이 찾아 고친 것

- **모두 같은 견습 마을에서 시작했다**: 서버 견습 세계는 사람이 하나라 들어온 차례가 늘 0번이어서, 첫 측정에서 다섯이 모두 같은 견습 마을(도시까지 4일+)·같은 목적지였다. 상인 번호로 시작 마을을 뽑게 고친 뒤 묶음이 2·4+·2·3·4+로 갈렸다.
- **봇이 채워지지 않았다**: 측정 준비(사람 자리에 봇 판단)를 "이미 봇이 있다"로 잘못 봤다. 봇 표시로 보게 고쳤다.

## 4. 만들며 찾아 고친 것

- **postgres.js가 JSON을 한 번 더 감쌌다**: `$1::json` 자리에 넘긴 글자열이 글자 하나로 저장되었다(세계 상태 전체가 문자열). PGlite 시험에서는 안 보이고 Deno 끝까지 시험에서 잡았다. `$1::text::json`으로 넘긴다.
- **모르는 명령에 서버가 터졌다**: 시뮬 명령 처리에 기본 갈래가 없었다. `badCommand`로 실패한다.
- **말 이름에 금칙어 검사가 없었다**(0.1.7 말 이름). 서버가 거른다.
- **같은 점수의 순위 차례가 세계마다 달랐다**: 결산 표가 세계마다 달라질 수 있었다. 세계 id·상단 id 순으로(코드 순서 비교).
- **세계에 들어갈 때 증서가 비었다**: 이름·얼굴·문장만 들고 들어가 지난 인장·칭호·연차가 세계의 증서에 없었다. 증서 전체를 들고 앉는다.
- **화면의 `!page.send(...)` 다섯 곳**: 명령을 비동기로 바꾸며 TypeScript가 못 잡는 꼴. 그대로면 서버 게임에서 늘 실패로 보였다.
- 위 3장의 둘(견습 마을, 봇 채우기).

## 6. 아직 안 한 것

- 실제 Supabase 배포와 그 위의 확인(pg_cron, 로그인, 메일). 2장.
- 화면 안 알림의 "띠": 서버가 낮·밤으로 나눈 알림(`away.delivery`)을 주지만, 화면은 지금처럼 "자리를 비운 사이" 쪽지 하나로 보인다. 열어 둔 동안 장날이 지나도 쪽지로 뜬다.
- 두 번째 시즌부터 견습 건너뛰기(비공개 테스트가 시즌 하나라).
- 게임 시작 화면·증서 목업이 오면 맞추기.
