# 0.0.3 점검 목록

기획 0.0.3 작업(0~4번)을 마친 뒤 정리한 것. 정해 줄 것은 `docs/questions.md`에 따로 있다.

## 1. 직접 확인해 주실 것

### 아이폰에서

컴퓨터와 같은 와이파이에서 `npm run dev -- --host`를 실행하고, 터미널에 나오는 `Network:` 주소를 사파리에서 연다.
아직 실제 아이폰에서는 한 번도 열어 보지 못했다. 아래는 컴퓨터 미리보기(휴대폰 크기)에서만 확인했다.

- [ ] **같은 맵이 나오는지**: `/dev.html?seed=20261008`을 열어 "지문"이 **`cf57897b`**인지. 다르면 사파리와 컴퓨터가 다른 맵을 만드는 것이라 바로 알려 주세요.
- [ ] **3D 지도**: 한 손가락으로 돌리기, 두 손가락으로 확대가 되는지. 화면 전체가 확대되지 않는지. 버벅이지 않는지.
- [ ] **수레 판**(장부 탭): 짐을 손가락으로 끌어 옮기기, 톡 눌러 돌리기가 되는지. 끄는 동안 화면이 같이 스크롤되지 않는지.
- [ ] **원정 카드**: 카드를 좌우로 넘겨 고르기가 되는지.
- [ ] **홈 화면에 추가**: 공유 → 홈 화면에 추가 후 주소창 없이 열리는지, 노치와 아래 홈 바에 글자가 가리지 않는지.
- [ ] **글자와 그림 크기**: 버튼이 누르기 편한지, 글자가 너무 작지 않은지.

### 한 판 해 보기

- [ ] 주소에 `?new`를 붙여 새 세계로 시작. 마을 화면 맨 아래 "시험용: 장날 바로 열기"로 날을 넘긴다.
- [ ] 사고팔기 → 장날 → 다른 마을로 이동 → 원정 → 음식 먹기·여관 → 수레 정리까지 한 바퀴 돌려 보고, 어색한 말이나 헷갈리는 곳을 알려 주세요.
- [ ] 개발용 화면 `/dev.html` 아래쪽 "경제 관찰"에서 360일을 돌려 시세 그래프를 보고, 경제가 그럴듯한지.

### 저장소와 배포

- [ ] **git 작성자 이름**이 임시로 `hatae1996`이다(이메일은 계정 이메일). 바꾸려면 `git config user.name "이름"` 후 지난 커밋들은 그대로 두거나, 다시 쓰고 싶으면 알려 주세요.
- [ ] **GitHub에 올리기와 미리보기 배포(GitHub Pages)**는 아직 하지 않았다. 방법은 README "미리보기 배포"에 있다. 비공개 저장소의 Pages는 유료 요금제에서만 된다.

## 2. 고쳐야 할 것 (개발 쪽)

기획 답을 기다리지 않고 할 수 있는 것과, 답에 따라 달라지는 것을 나눴다.

### 경제 균형 (가장 급함)

- **도구 부족**: 일꾼의 50~84%가 도구 없이 일한다(시드 5개, 360일). 도구 값이 마을마다 35~206. → `questions.md` 12번 답에 따라 고친다. 답 전에도 대장장이가 재료를 사 오는 길(NPC 상단이 대장간 마을로 광석·목재를 나르게)은 손볼 수 있다.
- **겨울 인구 감소**: 시드에 따라 겨울에 일꾼이 시작의 1/3까지 준다(31명 → 10명). → 11번 답에 따라.
- **가죽·광석 바닥 시세**: 생산 마을에선 가죽 4(기준 16), 도시에선 10~24. NPC 상단이 옮기는 양이 적어 차이가 계속 남는다. 플레이어 장삿길로는 좋지만, 도시 수요를 NPC가 거의 못 채운다.
- 개발용 관찰 화면에 **봇 돌리기**(CLAUDE.md의 dev 화면 역할)가 아직 없다. 기획서의 "평범하게 하는 사람이 시즌 중반쯤 3단계 고용주를 경험한다"를 맞추려면 플레이어 봇이 필요하다.

### 화면

- **원정 카드 그림**: 지금은 건물·풍경 그림(숲, 광산, 바다, 들판, 여관)을 돌려 쓴다. 기획서대로라면 카드 그림, 카드 뒷면, 넘기는 연출과 소리가 필요하다(다음 버전).
- **물품 아이콘이 없다**: 시세표, 수레 판, 원정 결과가 모두 글자다. 기획서 UI 에셋 목록의 "물품 9종 아이콘"이 오면 넣는다.
- **도시가 3D 지도에서 작다**: 탑과 집 다섯 채인데 멀리서 잘 안 보인다.
- **처음 하는 사람 흐름이 없다**: 첫 5분 안의 이익, 탭 하나씩 열기, 견습 기간, 노상인 안내. 인수인계에서 이번 범위 밖이라 하지 않았다.
- **화면 자동 테스트가 없다**: 수레 끌어 놓기가 아무 일도 안 하던 버그는 화면을 직접 써 보고서야 찾았다. 시뮬레이션은 테스트 678개가 있지만 화면은 손으로만 확인했다.

### 구조

- **저장이 바뀌면 처음부터**: 0.0.3에서 상태 모양이 바뀌어 저장 칸을 v2로 올렸고 예전 저장은 버린다. 시험하는 동안은 괜찮지만, 공개 전에는 예전 저장을 새 모양으로 옮기는 방법이 필요하다.
- **경제가 기기마다 같은지**: 맵은 지문으로 사파리와 Node가 같은지 확인할 수 있지만, 경제(장날 정산, 일꾼)는 아직 그런 확인이 없다. 서버를 붙이기 전에 경제 지문도 개발용 화면에 넣는 게 좋다.
- **3D 땅 그림 실험**: 그림체가 단색으로 정해졌으니, 개발용 화면의 "땅 그림" 켜기와 관련 코드(`src/view3d/tileArt.ts`)는 지워도 된다. 지금은 남겨 두었다.

## 3. 이번 범위 밖이라 하지 않은 것

멀티플레이와 서버, 시즌 랭킹, 은행, 물품 등급, 신문의 상단 동정, 견습 기간, 푸시 알림, 예약 주문, 창고 보관료, 소량 즉시 거래, 신문값, 정보원, 지도 정보 층(특색을 소문으로 알기), 마을 NPC 소문, 성장 단계(수레 바꾸기, 일꾼 고용).
