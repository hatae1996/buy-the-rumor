# 다음 기획 세션에 가져갈 질문

개발하며 생긴 질문과 결정이 필요한 것을 여기에 적는다. 답이 나오면 아래 "답이 나온 질문"으로 옮긴다.
질문마다 **지금 어떻게 만들어 두었는지**를 함께 적었다. 그대로 좋으면 "그대로"라고만 답해도 된다.
★는 다음 개발을 시작하기 전에 정해야 하는 것이다.

마지막 정리: 2026-10-10 (기획 0.1.1·0.1.2 반영)

## 열린 질문

84~94번과 1차 테스트 후기(`docs/기획전달-1차테스트-0.1.0.md`)는 답이 나왔다(아래 표, 기획 0.1.1·0.1.2). 0.1.1·0.1.2 작업에서 생기는 질문은 95번부터 적는다.

### 0.1.2 계획에서 생긴 질문 (docs/작업목록-0.1.2.md)

1차 테스트 후기 기획전달에서 물었는데 0.1.2 답에 없던 것이다. 기본안으로 만들어 두고 여기 남긴다.

95. **"Buy the Rumor" 랭킹을 언제 세나:** 지금은 수첩에 적힐 때 센다(밤마다 저절로 적혀 들은 날과 같았다). 기본안: 수첩에 적은 날로 센다. 도장도 적은 것에만 찍히니 맞춘다. 흘려들은 소문은 세지 않는다. 들은 날로 셀지?
96. **지난 신문:** 지금은 7일 안의 지난 신문도 산다. 0.1.2 답은 "신문팔이에게서 그날 것을 산다"이다. 기본안: 그날 신문만 판다(도시에서 먼 마을은 하루 늦게 도착한 것이 그날 신문). 견습 동안 무료는 그대로. 산 적 없는 날의 머리기사 한 줄 공짜 공개는 없앤다("자리를 비운 사이"는 산 신문의 머리기사만이라).
97. **소문이 아닌 것의 자리:** 원정에서 직접 본 것, 비둘기 소식, 장날 신청 현황 힌트도 지금 수첩에 섞여 들어간다. 기본안: 적기 단계 없이 소식 탭 "보고"에 저절로 남긴다. 수첩은 여관에서 듣고 내가 적은 소문만 담는다. 원정은 보류라 원정에서 본 것은 자리만 옮긴다.
98. **길에서 먹는 식량과 "먹기"(피로 회복):** 지금 음식을 먹으면 피로가 준다(하루 3끼까지). 기본안: 따로 둔다. 이동하는 날의 식량 1은 저절로 먹고 피로를 줄이지 않는다(떨어지면 피로가 오르기만). "먹기"는 그대로.
99. **수첩 한도:** 지금은 150줄이 넘으면 오래된 것부터 지운다. 기본안: 그대로 두고 적은 것만 센다. "무엇을 적을까" 고르게 하는 작은 한도(예: 30)는 두지 않는다.

61. **은행 맡기기·빌리기의 실제 동작.** 자리와 데이터 구조만 둔다. (0.0.6)
