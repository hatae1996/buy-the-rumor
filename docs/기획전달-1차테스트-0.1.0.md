## 1. 신문은 마을에서 산다 (+ 산 신문을 다시 보기)

**후기**
- 신문은 마을에 도착해서, 매일 신문 파는 사람이나 건물에서 산다. 산 신문에는 발행 날짜가 붙고, 소식 탭에 보관할 수 있다.
- 신문이 잘 안 보인다. 하나 사면 그 신문 내용을 쭉 보고 싶은데, 내가 어떤 신문을 샀는지도 모르겠다.

**지금**
- 신문은 장날마다 하나 나온다(그날 장날까지 세상의 소식). 소식 탭에서 **어디서든, 길 위에서도** 산다. 2냥, 7일 안의 지난 신문도 산다. 견습 동안은 무료.
- 사지 않은 날은 머리기사 한 줄만 보이고, 사면 같은 목록 안에서 그날 기사가 다 펼쳐진다. 신문이 날짜별 한 부로 묶여 보이지 않고, 산 신문만 모아 보는 곳도 없다.

**기획서와**
- "소식을 얻는 방법"에는 "신문은 장날마다 발행된다. 자리를 비운 사이 요약에서 오늘 신문의 머리기사를 보여 주고, 사면 전문을 읽는다"만 있고, 어디서 사는지는 없다.
- 후기 쪽이 "플레이어는 지금 있는 마을만 정확히 알고, 나머지는 날짜가 붙은 기억, 신문, 소문으로 안다"는 원칙에 더 잘 맞는다. 신문이 "그 마을에 와야 얻는 정보"가 된다.

**개발 쪽 의견**
- 신문은 마을의 신문 파는 곳(건물 카드 하나)에서 산다. 길 위에서는 못 산다.
- 산 신문은 소식 탭의 **신문함**에 한 부씩 날짜순으로 쌓인다. 누르면 그 신문 한 부를 신문 모양으로 처음부터 끝까지 읽는다. 사지 않은 날은 신문함에 없다.

**정해 주실 것**
- (가) 파는 곳: 모든 마을인가, 큰 마을·도시에만인가? 건물(신문 가판)인가, 사람(신문팔이)인가?
- (나) 지난 신문: 그 마을에서 며칠 전 것까지 파는가? (지금 7일)
- (다) 머리기사 무료 공개: "자리를 비운 사이"와 소식 탭에서 오늘 머리기사 한 줄은 지금처럼 공짜로 보이는가? 보이면 길 위에서도 머리기사는 안다.
- (라) 마을마다 신문이 다른가(그 지방 소식이 더 많다), 모든 마을이 같은 신문인가?
- (마) 신문함에 들어가는 수에 한도가 있는가?

## 2. 짐칸을 DREDGE 인벤토리처럼

**후기:** 짐칸을 게임 DREDGE의 인벤토리를 참고해 고친다. (함께 올린 그림 참고)

**지금**
- **규칙은 이미 DREDGE와 같다.** 물품마다 칸 조각 모양이 있고, 끌어다 놓고 톡 눌러 돌린다. 수레마다 판 모양이 다르다.
- 다른 점은 생김새다. 물품이 색칠한 네모 칸이고, 판이 수레 모양이 아니며, 고른 물건을 설명하는 칸이 없다.

**참고 그림에서 가져올 것:** 마차 그림 위에 놓인 격자, 칸 조각마다 물건 그림, 묶음 수량 배지, 위쪽 무게 막대(38 / 70), 아래쪽 고른 물건 설명(칸 수·무게·매입가), "빈칸 정리" 버튼.

**개발 쪽 의견:** 시뮬레이션은 거의 그대로, 화면만 고치면 된다. 그림이 오기 전에 화면 틀(무게 막대, 설명 칸, 수량 배지)부터 만들 수 있다.

**정해 주실 것**
- (가) 그림 목록: 물건 그림 9종(생선, 고기, 곡물, 목재, 가죽, 광석, 소금, 염장 식품, 도구)과 짐판 그림 5종(등짐/손수레, 짐수레, 마차 등 수레 4종과 창고). 6번에서 식량이 새 물품이 되면 하나 더. "UI 에셋 목록"에 넣어 주시면 그림을 받아 넣는다.
- (나) **매입가 표시:** 지금 짐은 물품·양·상한 정도만 기억하고 산 값은 기억하지 않는다. 보여 주려면 묶음마다 산 값을 기억하게 바꾼다(원정으로 얻은 것은 0). 넣을까? 넣으면 "이걸 얼마에 샀더라"를 장부에서 찾지 않아도 된다.
- (다) **빈칸 정리**(눌러서 짐을 빈틈없이 다시 쌓기): 넣어도 되나? 퍼즐처럼 직접 쌓는 재미가 줄어드는지 기획에서 판단해 주시길.

## 3. 아래 탭 5개: 마을, 지도, 짐, 장부, 소식

**후기:** 지도와 장부 사이에 짐(인벤토리) 탭을 넣어 5개로 하고, 장부와 짐을 나눈다.

**지금:** 탭 4개(마을, 지도, 장부, 소식). 짐은 장부 탭 맨 위에 있다.

**기획서와:** "화면 구성"에 "아래 탭 4개로 오간다"가 확정으로 적혀 있고, "UI 에셋 목록"의 탭 아이콘과 리본도 4개 기준이다.

**개발 쪽 의견**
- 아이폰 폭에서 5개여도 탭 하나가 약 75px로, 누르는 영역(44px 이상)은 넉넉하다.
- 짐 탭에 내 수레, 창고, 두 번째 행렬의 짐을 함께 두면 2번과 한 화면이 된다.

**정해 주실 것**
- (가) 탭 5개로 바꾸는 것 확정, 기획서 "화면 구성" 고치기.
- (나) 짐 탭에 무엇을 둘지: 내 수레만 / 수레 + 창고 / 수레 + 창고 + 두 번째 행렬.
- (다) 견습에서 짐 탭이 열리는 때 (지금 탭은 마을 → 장부 → 소식 → 지도 순으로 열린다).
- (라) 그림: 짐 탭 아이콘 1개, 5번째 리본 색.

## 5. 장부 정리

**후기:** 장부 탭이 정돈이 안 된 느낌이다. 가계부와 내 구매/판매 신청을 탭으로 나눠 화면을 분리한다.

**지금:** 장부 한 화면에 위에서부터 짐 → 신청(오늘 신청, 예약 주문) → 사람과 말(하루 유지비) → 시세(마지막으로 본 값) → 돈(손익)이 길게 이어진다.

**개발 쪽 의견:** 3번으로 짐이 빠지면, 장부 안에 작은 탭을 둔다.

| 작은 탭 | 들어갈 것 |
| --- | --- |
| 신청 | 오늘 낸 사기·팔기 신청, 예약 주문 |
| 가계부 | 날마다 들어오고 나간 돈, 하루 유지비 |
| (셋째 탭?) | 마지막으로 본 시세, 사람과 말 |

**정해 주실 것:** "시세"와 "사람과 말"을 어디에 둘지. 셋째 탭으로 / 가계부 아래로 / 시세는 지도 탭 마을 카드로 옮기기 등.

## 6. 식량

**후기:** 식량을 넣어 이동 거리에 따라 식량이 줄게 한다. 식량도 돈을 주고 사야 한다.

**지금**
- 음식(생선, 고기, 곡물, 염장 식품)은 있다. 먹으면 피로가 준다(하루 3끼까지, 신선할수록 많이). 먹지 않아도 이동은 된다.
- 말은 이미 길 위에서 수레에 실은 곡물을 먹는다(하루 조랑말 0.5, 짐말 1).
- 사람이 길에서 먹어야 하는 규칙은 없다.

**개발 쪽 의견**
- 새 "식량" 물품을 만들기보다, **지금 있는 음식을 길에서 먹게** 하는 쪽을 권한다.
  - 새 물품이 늘지 않는다(그림, 생산 일꾼, 시세표가 그대로).
  - 곡물·염장 식품의 수요가 늘어 장이 깊어진다. 열린 질문 91번(사람이 많으면 벌이가 목표 아래)에도 도움이 될 수 있다.
  - 염장 식품이 "오래 가는 길 음식"이라는 쓸모를 얻는다. 생선·고기는 금방 상하니 짧은 길용.
- 짐칸을 차지하게 하면 "장사 짐을 더 실을까, 먹을 것을 더 실을까"라는 선택이 생긴다.
- 넣으면 봇 상인도 먹어야 하니, 벌이 숫자(확인목록 3장)를 다시 재야 한다.

**정해 주실 것**
- (가) 식량은 지금 음식 물품인가, 새 물품인가?
- (나) 얼마나 먹나: 길 하루마다 1개? 지나는 칸 수마다? 고용한 일꾼·마부·짐꾼도 먹는가?
- (다) 모자라면: 피로가 쌓인다 / 느려진다 / 출발할 수 없다 / 짐을 버린다 중 어느 것?
- (라) 짐칸을 차지하는가? (권함: 차지한다)
- (마) 지금의 "먹기(피로 회복)"와 합칠지, 따로 둘지.
- (바) 마을에 머무는 날도 먹는가, 길 위에서만인가? (머무는 날은 여관 밥값으로 대신하는 안도 있다)

## 8. 튜토리얼

**후기:** 튜토리얼 수정이 필요하다.

**지금:** 견습 장면 7개. 시작 → 첫 원정 → 첫 짐 싣기 → 첫 판매와 첫 장날 → 첫 신문 → 첫 구매와 무게 → 졸업. 견습 마을에서는 시간이 흐르지 않고 "하루 보내기"로 넘긴다. 장면마다 노상인 한마디가 나온다.

**개발 쪽 의견:** 어디가 걸렸는지 알아야 고칠 수 있다. 1·3·6·9번이 바뀌면 "첫 짐 싣기", "첫 신문" 장면도 함께 바뀌고, 6번이 들어가면 "첫 식량" 같은 장면이 하나 늘 수 있다.

**정해 주실 것** (테스트 기억을 떠올려 적어 주시면 좋다)
- (가) 어느 장면에서 할 일을 몰랐나?
- (나) 너무 길었나, 짧았나? 건너뛰고 싶었던 장면은?
- (다) 말이 어려웠나? 노상인 말투나 안내 방식(대사만 / 손가락으로 가리키기 / 화면 어둡게 하고 한 곳만 밝히기)은?
- (라) 견습이 끝났을 때 "이제 뭘 하지?"가 있었나?

## 9. 소문 수첩

**후기:** 소문 수첩이 너무 정리가 안 되어 있다. 내가 실제로 들은 것도 아닌데 다 적혀 있는 것도 이상하다. 소문을 들으면 수첩에 적을지 말지를 내가 정하는 게 좋겠다.

**지금**
- 마을에 있으면 **밤마다 그 마을 소문꾼에게 저절로, 공짜로** 몇 개씩 듣는다. 들은 것은 모두 수첩에 적힌다. (전 기획 답 60: "지금처럼 밤마다 저절로 듣는다")
- 여관에서 술값을 내면 손님에게 먼 마을 소문을 하나 듣는다. 이것도 수첩에 적힌다.
- 원정에서 직접 본 것, 비둘기 소식, 장날 신청 현황 힌트도 같은 수첩에 섞여 들어간다.
- 수첩은 날짜순 한 줄 목록이고, 150줄이 넘으면 오래된 것부터 지운다. 나중에 사실이 확인되면 "맞았다 / 틀렸다" 도장이 찍힌다.

**기획서와:** 답 60과 부딪힌다. 랭킹 "Buy the Rumor"(사건 징조를 얼마나 일찍 들었나)도 지금은 수첩에 적힐 때 센다.

**개발 쪽 의견**
- "실제로 들은 것도 아닌데"는 **듣는 길이 눈에 보이지 않아서**인 것 같다. 밤사이 저절로 쌓이니 언제 누구에게 들었는지 실감이 없다.
- 안: 들은 소문은 그날 "오늘 들은 이야기"에 카드로 한 장씩 뜨고(누구에게, 어디서), **적기 / 흘려듣기**를 고른다. 흘려들은 것은 며칠 뒤 사라진다.
- 수첩은 적은 것만, 물품별·마을별로 묶어 보여 준다. 직접 본 것과 장날 힌트는 소문과 따로 둔다.

**정해 주실 것**
- (가) 듣는 길: 밤마다 저절로(지금) / 여관이나 사람에게 말을 걸 때만 / 둘 다(저절로 듣는 건 줄이고 카드로 보여 주기)?
- (나) 적지 않은 소문은 언제 사라지나? (그날 / 며칠 뒤)

## 10. 원정(바깥 탐색)이 애매하고 재미없다

**후기:** 바깥 탐색이 좀 애매하다. 재미도 없다. 고민해 봐야겠다.

**지금**
- 마을의 "바깥" 건물에서 원정을 떠난다. 지형(숲, 들, 바다, 산, 광맥 등)별 카드 덱을 넘기며 고르고, 도구 하나로 선택지 4번, 피로가 쌓인다.
- 기획 0.0.6에서 "장사가 주 수입, 원정은 밑천"으로 정해 원정 수확은 일부러 작게 두었다. 봇 측정에서도 원정꾼은 장사꾼보다 덜 번다(5명 세계에서 장사꾼이 2.4배).

**개발 쪽 의견:** 어떤 점이 재미없었는지에 따라 방향이 갈린다.

| 재미없던 까닭 | 고칠 방향 예 |
| --- | --- |
| 카드가 단조롭다, 고를 게 없다 | 갈림길 카드 늘리기, 위험과 보상이 큰 선택 |
| 얻는 게 너무 적다 | 수확을 키우거나, 원정에서만 얻는 것(희귀품, 지도 정보, 소문) 두기 |
| 시간이 아깝다, 장사가 낫다 | 원정은 견습과 초반의 밑천으로만, 이후엔 채집꾼에게 맡기기 |
| 장사 게임과 따로 논다 | 원정에서 본 것이 소문·사건 징조로 이어지게 (정보 얻는 길) |

**정해 주실 것**
- (가) 테스트에서 재미없었던 까닭 (위 표 중, 또는 다른 것).
- (나) 원정의 자리: 계속 주요 활동 / 초반 밑천용 / 정보 얻는 길 / 줄이거나 빼기.
